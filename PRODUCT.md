# Product

## Register

product

## Users

Household members watching lean-back **Live TV** channels in Plex. Admin (Brad) runs Orca Broadcast + ErsatzTV on the LAN. Family “request this forever” still goes through **Seerr**.

## Product Purpose

**Orca Broadcast** schedules virtual TV stations, downloads episodes/movies into a **staging** folder (not the normal Plex libraries), feeds **ErsatzTV** so Plex shows real Live TV channels with a guide, then **deletes** files after they air.

Success: flip to “Cops 24/7” in Plex and something is always on — without polluting Movies/TV Shows.

## Brand Personality

Broadcast · Precise · Quietly capable

Feels like a living-room control room: dark surfaces, clear schedule status, no ceremony.

## Anti-references

- Purple-glow “AI dashboard” kits
- Overseerr clones (Seerr already covers requests)
- Dense Sonarr walls with no hierarchy

## Design Principles

1. **Guide before chrome** — what’s on now / next should read at a glance.
2. **Staging is sacred** — never import Broadcast files into Movies/TV libraries.
3. **Safe deletes** — never delete a file while its block is `airing`.
4. **One action layer** — Refresh schedule / fill is the primary admin control.
5. **Trust Plex Live TV** — Orca directs; ErsatzTV + Plex present the tuner.
